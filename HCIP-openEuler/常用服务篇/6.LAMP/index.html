    1.LAMP架构概述

    1.1.什么是LAMP？

    LAMP是一个经典的Web应用技术栈，由四个开源组件组成：

    • Linux：操作系统。
    • Apache：Web服务器。负责处理HTTP请求，提供静态文件和动态内容。
    • MySQL/Mariadb：数据库管理系统。存储和管理网站数据。
    • PHP/Python/Perl：编程语言（通常指PHP）。服务器端脚本语言，处理动态内容。

    1.2.LAMP工作流程

    1. 用户浏览器中输入URL，通过DNS正向解析出目标IP地址。
    2. 用户向目标服务器发送HTTP请求到Web服务器。
    3. Apache判断请求类型：
    4. 如果是静态资源（如HTML、CSS、图片）直接处理并返回。

    5. 如果是动态资源（如PHP脚本）将请求交给PHP。

    6. PHP查询数据库获取文章内容、评论、作者等信息。

    7. PHP将内容进行整合，发送给Apache。

    8. Apache生成网页响应给客户端。

    9. 浏览器显示网页内容。

    1.3.用户查看文章的过程

    1. 访问 example.com/blog/my-article
    2. Apache交给PHP处理
    3. PHP查询数据库：SELECT * FROM wp_posts WHERE 标题='my-article'
    4. 从数据库获取文章内容
    5. PHP将内容填充到主题模板
    6. 生成HTML返回给用户

    1.4.数据存放

    在LAMP部署wordpress中，Linux文件系统中主要存储的是wordpress的程序文件：

    /wordpress/
├── wp-admin/      # 管理后台代码
├── wp-includes/   # 核心函数库
├── wp-content/    # 主题、插件、上传的图片
│   └── uploads/   # 用户上传的图片文件
├── index.php      # 入口文件
└── wp-config.php  # 配置文件

    对于真正和博客相关的数据，例如：用户、密码、文章等都存放在数据库中：

    MySQL数据库 → wp_posts表
├── ID: 1
├── 标题: "我的第一篇博客"
├── 内容: "这是文章正文..."
├── 作者: admin
├── 发布时间: 2024-01-01
├── 分类: 技术
└── 标签: PHP,教程

    1. 下载并配置wordpress
    [root@LAMP ~]# wget https://wordpress.org/latest.tar.gz # 从官网下载wordpress

[root@LAMP ~]# mkdir /lamp  # 创建wordpress目录

[root@LAMP ~]# mv latest.tar.gz /lamp   # 移动wordpress文件至/lamp目录

[root@LAMP lamp]# cd /lamp/ # 进入目录

[root@LAMP ~]# tar -zxvf latest.tar.gz  # 解压缩

[root@LAMP ~]# chown -R apache:apache /lamp     # 修改目录所属 

[root@LAMP ~]# chmod -R 755 /lamp   # 修改权限

[root@LAMP lamp]# cd wordpress/ # 进入wordpress配置目录

[root@LAMP wordpress]# cp -a wp-config-sample.php wp-config.php     # 复制配置模板

[root@LAMP wordpress]# vim wp-config.php    # 编辑修改wp配置文件
    define( 'DB_NAME', 'wordpress' );   # 指定数据库名称
    define( 'DB_USER', 'wp_user' );     # 指定数据库用户
    define( 'DB_PASSWORD', 'Huawei@123' );  # 指定数据库密码
    1. 创建wordpress需要使用的数据库和数据库用户
    [root@LAMP wordpress]# mysql -u root -p
    MariaDB [(none)]> CREATE DATABASE wordpress;    # 创建数据库

    ### 创建wordpress数据库用户，localhost代表只能本机登录
    MariaDB [(none)]> CREATE USER 'wp_user'@'localhost' IDENTIFIED BY 'Huawei@123';

    ### 授予权限，ALL代表所有权限，ON是范围只针对wordpress数据库，TO给予用户
    MariaDB [(none)]> GRANT ALL PRIVILEGES ON wordpress.* TO 'wp_user'@'localhost';

    ### 刷新权限让Mysql立即重新加载权限表，使授权生效 
    MariaDB [(none)]> FLUSH PRIVILEGES;

    ### 退出数据库
    MariaDB [(none)]> EXIT;
    1. 上传网站证书至服务器
    [root@LAMP ~]# mkdir /opt/pki   # 创建证书存放目录

[root@LAMP ~]# cp gugujun.site.zip /opt/pki/    # 复制证书压缩包至目录

[root@LAMP ~]# cd /opt/pki  # 进入该目录

[root@LAMP pki]# unzip gugujun.site.zip # 解压缩
    1. 配置apache HTTPS
    [root@LAMP pki]# vim /etc/httpd/conf.d/ssl.conf # 编辑HTTPS虚拟站点
<VirtualHost _default_:443>
ServerName www.gugujun.site # 绑定域名
DocumentRoot /lamp/wordpress/   # 网站根目录
SSLCertificateFile /opt/pki/certificate.crt # 证书
SSLCertificateKeyFile /opt/pki/private.key  # 私钥
<Directory /lamp/wordpress> # 网站目录及权限设置
        options Indexes FollowSymLinks
        Require all granted
</Directory>

[root@LAMP wordpress]# systemctl restart httpd

### 查看所有已经发布的文章：
SELECT 
    ID, 
    post_title AS 标题,
    post_date AS 发布时间,
    post_author AS 作者ID
FROM wp_posts 
WHERE post_type = 'post' 
AND post_status = 'publish'
ORDER BY post_date DESC;

+----+--------------+---------------------+----------+
| ID | 标题         | 发布时间            | 作者ID   |

|  5 | 测试         | 2025-12-08 08:27:26 |        1 |
|  1 | Hello world! | 2025-12-08 08:18:11 |        1 |

### 查看具体文章内容：
SELECT 
    ID,
    post_title AS 标题,
    post_content AS 内容,
    post_date AS 发布时间
FROM wp_posts 
WHERE ID = 5;

+----+--------+---------------------------------------------------------------------------------------+---------------------+
| ID | 标题   | 内容                                                                                  | 发布时间            |
+----+--------+---------------------------------------------------------------------------------------+---------------------+
|  5 | 测试   | <!-- wp:paragraph -->
<p>你好这是一个测试文章！</p>
<!-- /wp:paragraph -->            | 2025-12-08 08:27:26 |
+----+--------+---------------------------------------------------------------------------------------+---------------------+
1 row in set (0.000 sec)
    表名 主要用途 存储内容示例
    wp_posts 核心表 - 存储所有内容 文章、页面、附件、导航菜单
    wp_postmeta 文章的扩展信息 自定义字段、特色图片、浏览量等
    wp_users 用户信息 用户名、邮箱、密码哈希
    wp_usermeta 用户的扩展信息 用户角色、个人设置、头像等
    wp_comments 评论信息 评论内容、作者、时间
    wp_commentmeta 评论的扩展信息 评论评分、审核状态等
    wp_terms 分类/标签/术语 分类名称、标签名称
    wp_term_taxonomy 术语分类法 区分是分类(category)还是标签(tag)
    wp_term_relationships 关联表 文章和分类/标签的关联关系
    wp_termmeta 术语扩展信息 分类描述、缩略图等
    wp_options 网站设置 站点标题、固定链接、主题设置
    wp_links 友情链接 博客链接功能（已很少用）

    在wordpress中所有和博客相关的内容数据都是记录在数据库中的，包括文章内容不是以文件形式存放在系统中，而是数据库数据。所以，对于wordpress最重要的是数据库，当你需要重新部署wordpress或迁移只要保证数据库内容完整，其余的随便改。
