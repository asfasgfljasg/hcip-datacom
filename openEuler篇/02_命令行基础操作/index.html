    二、命令行基础操作

    Linux命令语法格式

    command [options] [arguments]
    • command命令：必须存在，这是要执行的操作的核心。
    • options选项/参数：可选，用于修改命令的行为，通常以-或--开头。
    • 一条Linux命令根据其选项有不同的含义。多个选项也可组合在一起使用，这种情况下用一个-就可以了，例如:ls -la。
    • arguments参数/操作对象：可选，指定命令操作的目标对象，如文件名、目录名、用户名等，意为对谁执行。

    1.帮助命令

    Linux支持的命令非常非常多，不同的命令其参数的含义也是各不相同，若让我们一一记忆下来是不太可能的。Linux提供给我们帮助命令，可通过帮助命令查看命令与参数的含义。

    1.1.whatis命令

    在Linux中，whatis是一个简单且使用的工具，用于快速显示命令的简短描述。它本质上是从系统的man page数据库中提取命令的简要说明（即man手册的name部分）。

    基本用法如下：

    whatis [选项] [命令名称]

    注意：由于openEuler把软件包和帮助包拆分了，意味着当我们安装完软件后，还需要额外安装软件（命令）帮助包。如果你没有安装，使用whatis命令查询时，会出现如下回显：

    [root@qyt-gujun ~]# whatis ls
ls：没有合适结果。
[root@qyt-gujun ~]# man ls
没有 ls 的手册页条目

    之前有提到过Linux的基础命令（工具）是由GNU 项目提供的。这些基础命令在Linux中是通过安装coreutils这个安装包实现的，coreutils包是内置在系统中的。但由于之前介绍的原因，在openEuler中没有默认安装coreutils的帮助包，所以需要自行额外安装。一般帮助包的名称可能是PackageName-[help|doc|manual]。

    在你安装完对应的帮助包后，它会自动被系统加载到man的文件路径/usr/share/man/下。

    安装方法如下：

    1. 查询命令对应文件的位置：which cat
    2. 通过文件路径查询该命令所属软件包：rpm -qf /usr/bin/cat

    3. 通过查询出的结果，通过命令yum search coreutils查询

    4. 安装查询到的软件包的帮助包：yum install coreutils-help -y

    使用示例：

    [root@qyt-gujun ~]# whatis ls
ls (1)               - list directory contents

[root@qyt-gujun ~]# whatis cat
cat (1)              - concatenate files and print on the standard output

    1.2.内建与外部命令

    如果你执行whatis cd命令你会发现是没有任何结果的，因为cd是一条内建命令。

    可通过type命令确认命令的类型：

    [root@qyt-gujun ~]# type cd
cd 是 shell 内建

[root@qyt-gujun ~]# type cat
cat 是 /usr/bin/cat

    外部命令

    外部命令本质上就是一个程序，它们是独立于shell的可执行程序文件，类似于word、excel一样。外部命令通常存储在系统的/bin、/usr/bin、/sbin、/usr/sbin目录中。

    可以通过which命令查找到他们的位置：

    [root@qyt-gujun ~]# which ls
/usr/bin/ls
[root@qyt-gujun ~]# which vim
/usr/bin/vim

    运行原理如下：

    • 当您在 Shell 中输入一个命令（如 ls）并按下回车时，Shell 会做以下几件事：
    • 解析命令：Shell 先判断这是不是它自己内部的命令（内建命令）。如果不是，就进入下一步。
    • 搜索路径：Shell 会按照 $PATH这个环境变量中定义的目录顺序，逐个目录去查找有没有名为 ls的可执行文件。echo $PATH可以查看搜索路径。
    • 创建子进程：一旦在 /usr/bin/ls找到了这个程序，Shell 会创建一个新的子进程。
    • 执行程序：在这个新的子进程中，加载并执行 /usr/bin/ls这个程序。
    • 返回结果：程序执行完毕后，子进程终止，控制权交回给父进程（即 Shell）。

    内建命令

    内建命令是Shell自身的一部分，不是外部的独立程序。内建命令的代码直接编译在Shell解释器内部，不是单独的文件，在/bin目录下是找不到内建命令的。因为内建命令不是独立程序，所以没有独立的man pahe。

    常见的内建命令有cd、exit、export、alias、source、history等。

    为什么cd必须是内建命令？

    在Linux/Unix中，每个进程都有自己独立的工作目录。如果 cd是一个外部程序，那么当Shell为它创建子进程后，cd命令只会改变它自己这个子进程的当前目录。子进程运行结束后，目录改变的效果就随之消失了，父进程（Shell）的当前目录丝毫未变。

    查看内建命令的帮助：

    1. help command

    1. man bash：查看整个shell的手册，在里面搜索相关章节

    1.3.help命令

    help也是帮助命令，用来查看命令的作用与参数含义。但是help只适用于内建命令。

    语法：

    help [选项] [命令名称]
-d 仅显示命令的简短描述
-s 仅显示命令的语法格式

    使用方法

    1. 直接输入help会显示当前shell所支持的所有内建命令的列表和一个简短的描述。

    1. 查询具体内建命令的详细帮助

    1. 查看命令的简短描述

    1. 查看命令的语法

    1.4.--help参数

    --help是 GNU 编码标准 中规定的一个选项。绝大多数遵循 GNU 标准的命令行工具（如 coreutils包中的 ls, cp, mv, grep等）都支持它。

    它的目的是为用户提供一种快速、标准化的方式来获取命令的使用说明，而无需翻阅冗长的 man手册。

    语法：

    [命令名] --help

    --help输出的信息有时会很长，一屏显示不完。可以将其输出通过管道传递给分页器。

    ls --help | less    # 更推荐，支持上下滚动
ls --help | more    # 只能向下翻页

    1.5.man命令

    man本身是一个外部命令（通常是 /usr/bin/man），它的作用是格式化和显示在线参考手册页，使用man会进入man page界面，而不是直接打印在在控制台上。

    基本语法：

    man [选项] [手册页名称]

    章节结构：

    部分名称 内容描述 示例 (man ls中可能看到的内容)
    NAME（名称） 命令或函数的名称，以及一行简短的描述。 ls - list directory contents
    SYNOPSIS（概要） 极其重要！ 显示命令的语法格式，包括所有选项和参数。[]表示可选，|表示“或”，... 表示可重复。
    DESCRIPTION（描述） 核心内容。 详细描述命令的功能以及每个选项的具体含义。 解释 -l, -a, -h等每个选项的作用。
    OPTIONS（选项） 有时会单独列出选项的说明（但通常合并于 DESCRIPTION 中）。
    EXAMPLES（示例） 一些实用的使用示例（并非所有 man page 都有）。
    EXIT STATUS（退出状态） 命令执行完成后返回的退出代码及其含义。 0表示成功，非 0表示各种错误。
    SEE ALSO（参见） 列出与当前主题相关的其他命令或手册页。 对于 man grep，可能会看到 sed(1), awk(1), regex(7)
    AUTHOR, BUGS, COPYRIGHT 作者、报告 Bug 的方式和版权信息。

    手册的章节：

    Man pages内容庞大，为了有效组织，它们被分成了不同的章节。同一个名称（如 printf）可能既是一个命令又是一个 C 语言函数，它们会出现在不同的章节中。

    章节编号 内容类型 示例
    1 用户命令（所有用户都可以执行的命令） man 1 ls, man 1 cp
    2 系统调用（内核提供的函数） man 2 open, man 2 read
    3 库函数（程序库中的函数，如 C 库 libc） man 3 printf, man 3 malloc
    4 特殊文件（通常指 /dev下的设备文件） man 4 null, man 4 random
    5 文件格式与约定（配置文件的格式说明） man 5 passwd, man 5 fstab
    6 游戏 man 6 intro
    7 杂项（概述、约定、协议等） man 7 ascii, man 7 signal
    8 系统管理命令（通常需要 root 权限才能执行） man 8 fdisk, man 8 ifconfig
    9 内核例程（非标准）

    指定章节查询：

    如果一个名称在多个章节都存在，默认会返回编号最小的章节。你可以指定章节号来精确查找。

    man 1 printf   # 查看 Shell 命令 printf 的文档
man 3 printf   # 查看 C 语言函数 printf 的文档
man 5 passwd   # 查看 /etc/passwd 配置文件格式的文档
man 7 signal   # 查看 Linux 信号列表的文档

    man page中的快捷键：

    打开man page后，实际上是进入了一个叫做 less的分页器。以下是一些极其常用的导航快捷键：

    快捷键 作用
    空格键 或 Page Down 向下翻一页
    b 或 Page Up 向上翻一页
    /（后跟关键词） 向下搜索。例如 /pattern
    ?（后跟关键词） 向上搜索。例如 ?pattern
    n 重复上一次搜索，向前查找下一个匹配项
    N 反向重复上一次搜索，向后查找上一个匹配项
    g 跳转到第一行
    G 跳转到最后一行
    q 退出并返回命令行
    h 显示 less分页器的帮助菜单

    常用选项：

    选项 作用
    -f 显示命令的简短描述（等同于 whatis命令）
    -k 在所有手册的 NAME 部分中搜索关键词（等同于 apropos命令）
    -a 显示所有匹配的手册页，而不仅仅是第一个
    -w 显示手册页文件的路径位置，而不是显示内容

    2.文件管理命令

    2.1.Linux文件目录结构

    Linux系统将所有硬件、软件、配置和数据都组织成文件的形式，并放置在一个单一的、树形的目录结构中。这个结构的起点是根目录 /。所有其他目录都是它的子目录。这种设计的核心思想是：一切皆文件。

    目录路径 英文全称/含义 中文解释与用途
    / Root 根目录。整个文件系统层次的起点。所有其他目录都挂载在它之下。
    /bin Essential user Binaries 基础用户二进制命令。存放所有用户都可使用的、最基础的单用户模式也需要的命令，如 ls, cp, bash, cat。
    /boot Boot Loader Files 启动加载文件。包含 Linux 内核、GRUB 引导程序等系统启动所需的文件。不要轻易修改。
    /dev Device Files 设备文件。包含所有硬件设备的特殊文件。如 /dev/sda代表第一块硬盘，/dev/null是“黑洞”设备。
    /etc Etcetera (Configuration Files) 系统配置文件。包含所有系统和应用程序的配置文件。如 /etc/passwd（用户账户）、/etc/hosts（主机名映射）。
    /home User Home Directories 用户家目录。每个普通用户都有一个以其用户名命名的子目录在这里（如 /home/alice），用于存放个人文件和配置。
    /lib, /lib64 Essential Libraries 系统库文件。包含 /bin和 /sbin中命令所依赖的共享库文件和内核模块。
    /media Removable Media 可移动媒体挂载点。系统自动挂载 U 盘、光盘等可移动设备的位置。
    /mnt Temporary Mount Point 临时挂载点。管理员手动临时挂载文件系统（如另一个硬盘分区）的目录。
    /opt Optional Application Software 可选应用软件。通常用于安装第三方或额外的应用程序。
    /proc Process & Kernel Information 进程与内核信息。一个虚拟文件系统，以文件形式展示系统进程和内核信息（如 CPU、内存）。文件内容动态生成。
    /root Root User's Home Directory root 用户的家目录。超级管理员的家目录，不同于根目录 /。
    /run Application Runtime Data 应用运行时数据。存储系统启动以来运行中的进程的临时数据（如 PID 文件、套接字）。
    /sbin System Binaries 系统管理命令。存放系统管理、修复等需要 root 权限才能执行的命令，如 fdisk, ifconfig, reboot。
    /srv Service Data 服务数据。存放本机提供的服务所产生的数据（如网站文件、FTP 文件）。
    /sys System Information 系统信息。另一个虚拟文件系统，用于与内核交互、管理和配置硬件设备。
    /tmp Temporary Files 临时文件。所有用户都可读写的位置，存放临时文件。系统重启后可能被清空。
    /usr Unix System Resources Unix 系统资源。二级目录，包含绝大多数用户程序和文件。其子目录结构类似根目录（有 /usr/bin, /usr/lib, /usr/include等）。
    /var Variable Data 可变数据。存放经常变化的文件，如日志 (/var/log)、缓存 (/var/cache)、邮件队列、数据库文件等。

    2.2.导航与查看

    pwd命令

    pwd（print word directory）：该命令用于显示当前工作目录。

    [root@localhost usr]# cd /bin
[root@localhost bin]# pwd
/bin

[root@localhost bin]# pwd -P
/usr/bin
    • -P：显示当前工作目录真实的目录路径。

    cd命令

    cd（change directory）：该命令用于改变当前的工作目录。

    切换到绝对路径：cd /etc/sysconfig/network-scripts

    切换到相对路径：cd ./network-scripts

    特殊用法：

    在Linux中每个目录都有两个特殊目录.和..，.代表当前所处目录，..代表当前所处目录的上级目录。

    • 切换到上级目录：cd ..
    • 切换到当前用户家目录：cd ~或cd
    • 切换到指定的用户主目录：cd ~username
    • 切换到上次的工作目录：cd -
    • 切换到当前目录：cd .

    ls命令

    ls（list directory contents）：该命令用于显示工作目下的内容。

    常用参数：

    • -a：显示目录中所有文件及目录，包含隐藏文件
    • -d：只列出目录当前目录或指定目录的属性，不递归列出目录内的文件
    • -l：显示目录或文件的详细信息
    • -A：与-a相同，但不列出.和..
    • -t：按照修改时间进行降序排序
    • -r：倒序显示文件和目录
    • -F：在列出的文件名后加上符号，可执行文件"*"，目录"/"
    • -R：递归显示目录中的所有文件和子目录
    • -h：以人类可读的方式，显示目录和文件的大小

    文件类型

    • d：表示这是一个目录 (Directory)。
    • -：表示这是一个普通文件。
    • l：表示这是一个符号链接 (Link)，类似于快捷方式。
    • 其他不常见的还有 c（字符设备）、b（块设备）、s（套接字）等。

    2.3.文件与目录操作

    touch命令

    touch：该命令用于创建文件或修改时间戳。

    • 文件名最好加上后缀名，可方便知晓文件的类型。在创建文件时，文件名最多不能超过255个字符。

    • 文件名不可以用/，其他都可以，如果要使用特殊字符作为文件名，请用单引号把它引起来。

    动作：

    • 若该文件不存在，则创建文件
    • 若该文件已存在，则更新时间戳，不加任何参数，会修改除Btime外所有的时间戳
    • Atime：文件最后一次被访问的时间
    • Mtime：文件内容最后一次被修改的时间
    • Ctime：文件状态最后一次被改变的时间
    • Btime：文件创建的时间，如果该时间被改变，可能是文件被覆盖导致的。而vim在保存文件时，实际上是对文件进行覆盖。

    常用参数：

    • -a：改变文件的Atime
    • -m：改变文件的Mtime
    • -c：改变文件的Mtime
    • -d：设定时间与日期，可以使用各种不同的格式

    mkdir命令

    mkdir（make directory）：该命令用于创建目录

    常用参数：

    • -p：递归创建目录，若父目录不存在，则先创建父目录，再创建子目录。
    [root@qyt-gujun ~]# mkdir ./a/b/c/d

    2.5.查找与定位

    2.5.1.find命令

    用于在目录树中递归地搜索和定位文件和目录。它不仅仅能按文件名查找，还能根据文件大小、修改时间、权限、所有者等几乎任何你能想到的条件进行搜索，并对找到的文件执行操作。

    find [路径...] [表达式]

    查找：

    按照文件名查找：

    • -name "模式": 按文件名搜索，区分大小写。支持通配符 *(匹配任意字符)、?(匹配单个字符)。
    • -iname "模式": 按文件名搜索，不区分大小写。
    find /home -name "*.txt"          # 在 /home 目录下查找所有 .txt 文件
find . -name "project.*"          # 在当前目录及其子目录中查找名为 project. 开头的文件
find /etc -iname "*conf*"         # 在 /etc 目录下查找文件名中包含 "conf" 的文件（不区分大小写）

    按照文件类型查找：

    • -type f: 查找普通文件
    • -type d: 查找目录
    • -type l: 查找符号链接 (软链接)
    • -type b, -type c: 查找块设备和字符设备
    find /var -type f -name "*.log"   # 在 /var 目录下查找所有 .log 类型的普通文件
find . -type d -name "src"        # 在当前目录下查找所有名为 src 的目录

    按照文件大小查找：

    • 根据文件大小进行搜索。单位可以是：

    • c: 字节

    • k: 千字节 (KiB)

    • M: 兆字节 (MiB)

    • G: 吉字节 (GiB)

    find / -size +100M                # 在根目录下查找大于 100MB 的文件
find . -size -10k                 # 在当前目录下查找小于 10KB 的文件
find ~ -size +50M -size -100M     # 在家目录下查找大于 50MB 且小于 100MB 的文件

    按照时间查找：

    • 根据文件的修改时间、访问时间或状态改变时间来查找。时间以天为单位。

    • -mtime n: 文件内容在 n天前被修改过。

    • -atime n: 文件在 n天前被访问过。

    • -ctime n: 文件状态（如权限、所有者）在 n天前被改变过。

    • +n: 表示超过 n 天。

    • -n: 表示不足 n 天。

    • n: 表示正好 n 天。

    find /var/log -mtime -1          # 在 /var/log 目录下查找最近 1 天内修改过的文件
find /tmp -atime +30             # 在 /tmp 目录下查找超过 30 天未被访问的文件（可用于清理）
find . -mtime 0                  # 查找今天内修改过的文件

    按照权限查找：

    • -perm 644: 查找权限正好是 644 的文件。
    • -perm -644: 查找权限包含 644 的文件（即权限至少是 644）。
    • -user username: 查找属于用户 username的文件。
    • -group groupname: 查找属于用户组 groupname的文件。
    find . -perm 644                 # 查找权限为 644 的文件
find /home -user alice           # 查找 /home 目录下所有属于用户 alice 的文件

    动作：

    1. 默认动作：打印 (-print)

    2. -print是默认动作，将完整文件名输出到标准输出。

    3. 删除文件（-delete）不建议！

    # 先检查会找到哪些文件
find /tmp -name "*.tmp" -type f
# 确认无误后，再删除
find /tmp -name "*.tmp" -type f -delete

    1. 执行命令（-exec）

    2. 语法：-exec command {} \;

      • {}: 是一个占位符，在执行时会被替换为当前正在处理的文件路径。

      • \;: 表示命令的结束，必须转义。

    # 将当前目录及其子目录下所有的 .txt 文件打包成 archive.tar
find . -name "*.txt" -exec tar -rvf archive.tar {} \;

# 查找所有 .jpg 文件并将其复制到 /backup/images 目录
find . -name "*.jpg" -exec cp {} /backup/images/ \;

# 查找并交互式删除所有名为 core 的文件（会提示确认）
find / -name "core" -exec rm -i {} \;

    [root@qyt-gujun ~]# tar -rvf test.tar A

    • 解压压缩包：可以加-C

    2.7.链接

    链接（Link）是一种让多个文件名指向同一个文件数据的方式，分为硬链接Hard Link和软连接Symbolic Linx。

    2.7.1.硬链接

    硬链接直接指向文件的索引节点inode，与原始文件共享相同的磁盘存储。不可以跨文件系统做硬链接，因为inode是文件系统局部的。不能够链接目录。多个硬链接实际上是同一个文件的不同访问入口，它们共享相同的inode和文件数据，对其中任何一个硬链接所作的修改都会反映到其他链接上。

    当你做了硬链接后，删除其中一个硬链接不会影响其他硬链接和原始文件数据，只有当所有硬链接都被删除后，文件数据才会被真正从磁盘上删除。

    2.7.2.inode

    inode是什么？

    文件存储在硬盘上，硬盘的最小存储单位叫做扇区，每个扇区储存512字节相当于0.5KB。

    操作系统读取硬盘的时候不会一个一个扇区挨个读取，效率太低。而是一次性连续读取多个扇区，即一次性读取一个块block。块是由多个扇区组成的，是文件存储的最小单位，块的大小常见4KB，即八个扇区组成一个块。

    文件的数据都存储在块中，我们还必须找到一个地方存储文件的元数据，例如文件所属用户、所属组、权限、日期等信息。这种存储文件元数据的区域叫做inode索引节点。每一个文件都有对应的inode，里面包含了与该文件有关的一些信息。

    inode的内容

    字段 说明
    文件类型 普通文件（-）、目录（d）、符号链接（l）、设备文件（c/b）等
    权限（mode） 文件的读/写/执行权限（如 rw-r--r--）
    所有者（UID/GID） 文件所属用户和组
    大小（Size） 文件的字节大小
    时间戳 创建时间（ctime）、修改时间（mtime）、访问时间（atime）
    硬链接计数 指向该 inode 的硬链接数量（见 ls -l的第二列）
    数据块指针 指向文件实际数据存储的磁盘块（直接/间接指针）

    可以使用stat命令查看某个文件的inode信息：

    [root@qyt-gujun ~]# stat A

    用户访问文件的过程

    当你在命令行输入 cat file.txt时，系统会按以下步骤处理：

    1. 解析文件名：
    2. 通过目录项（directory entry）找到 file.txt对应的 inode 号。
    3. 目录本质是一个映射表，存储 文件名 -> inode的关系（例如 /home目录下可能有条目 file.txt -> inode 123456）。
    4. 读取 inode 信息：
    5. 根据 inode 号从文件系统的 inode table 中加载元数据（权限、大小、数据块位置等）。
    6. 访问数据块：
    7. 根据 inode 中记录的数据块指针，从磁盘读取文件内容。

    所以，没有inode是无法读取到文件内容的。

    inode的存储

    inode也会消耗硬盘的存储空间，所以硬盘格式化的时候，操作系统会自动将硬盘分成两个区域。一个是数据区用来存放文件的数据，另一个是inode区用来存放inode所包含的信息。

    每个inode节点的大小，一般是128字节或256字节。inode节点的总数，在格式化时就给定，一般是每1KB或每2KB就设置一个inode。假定在一块1GB的硬盘中，每个inode节点的大小为128字节，每1KB就设置一个inode，那么inode table的大小就会达到128MB，占整块硬盘的12.8%。

    2.7.4.软链接

    软链接（Symbolic Link）也叫符号链接，是Linux系统中一种特殊的文件类型，它类似于Windows的快捷方式。软链接本身是一个独立的文件，但它存储的是目标文件的路径，而不是实际数据。当访问软链接时，系统会自动跳转到目标文件。

    软链接的特点：

    1. 独立文件：软链接有自己的 inode 和存储空间（存放目标路径）。
    2. 可以跨文件系统：可以链接到不同磁盘或分区的文件。
    3. 可以链接目录：软链接可以指向目录。
    4. 依赖目标文件：如果目标文件被删除，软链接会变成“悬空链接”（失效）。
    5. 权限不影响目标文件：软链接的权限不影响目标文件的权限。

    命令语法：

    ln -s 目标文件或目录 软链接名
    • -s：代表创建软链接

    创建文件的软链接：

    [root@qyt-gujun ~]# echo "Hello World" > original.txt   # 创建原文件

[root@qyt-gujun ~]# ln -s original.txt symlink.txt  # 创建软链接

[root@qyt-gujun ~]# ls -l symlink.txt original.txt  # 查看现象
-rw-r--r-- 1 root root 12  9月 21 23:29 original.txt
lrwxrwxrwx 1 root root 12  9月 21 23:30 symlink.txt -> original.txt

    创建目录的软链接：

    [root@qyt-gujun ~]# mkdir mydir
[root@qyt-gujun ~]# ln -s mydir mydir_link
[root@qyt-gujun ~]# ll mydir_link
lrwxrwxrwx 1 root root 5  9月 21 23:31 mydir_link -> mydir

    查看软链接指向的目标：

    [root@qyt-gujun ~]# readlink symlink.txt
original.txt

    修改软链接的目标：

    [root@qyt-gujun ~]# ln -sf A symlink.txt
[root@qyt-gujun ~]# readlink symlink.txt
A

    删除软链接：

    rm symlink.txt  # 仅删除软链接，不影响目标文件

    查找软链接：

    [root@qyt-gujun ~]# find . -type l
./symlink.txt
./mydir_link
