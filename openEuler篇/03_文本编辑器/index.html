    三、文本编辑器

    1.vim编辑器

    1.1.vim编辑器命令格式

    vim [文件名] [参数]

    常见参数：

    • -c：打开文件前先执行指定的命令
    • -R：以只读方式打开，但是可以强制保存
    • -M：以只读方式打开，不可以强制保存
    • -r：恢复崩溃的会话
    • +num：从第num行开始

    1.2.vim编辑的三种模式

    vim编辑器有三种模式，在不同的模式下操作内容不同：

    • 普通模式(Normal Mode)：该模式不可编辑文本内容，可执行移动光标、删除、复制、粘贴、撤销等操作。
    • 插入模式(Insert Mode)：用于输入和编辑文本内容，可在键盘输入i、a、o进入插入模式，按ESC退出到普通模式。
    • 命令模式(Command Mode)：用于保存文件、退出vim、搜索提出按、配置设置等。用于执行一些高级、复杂的命令。通过:进入命令模式，命令会显示在编辑器窗口的最底部，输入命令按Enter执行，按ESC可退出到普通模式。

    1.3.vim的基本操作

    vim练习文本：

    Welcome to your Vim practice session. This text is designed to help you master the basic movements and commands of Vim, the powerful modal editor.

The goal is to keep your hands on the home row and use keystrokes efficiently. Remember: to start typing, press 'i' for insert mode. To return to normal mode and issue commands, press the ESC key.

Let's practice some common operations:
- Moving with h, j, k, l
- Deleting words with 'dw'
- Deleting lines with 'dd'
- Copying lines with 'yy'
- Pasting with 'p'
- Undoing with 'u'

Here is a line with some "quotes" and (parentheses). Can you navigate between them?

Find the word "dragon" in this text. It appears only once. Use the search command /dragon to locate it quickly.

Final challenge: This line has a typo: "teh" should be "the". Use your Vim skills to find and correct it.

Happy practicing! The journey to Vim mastery is long but incredibly rewarding.
    1.3.1.普通模式下的基本操作

    导航

    • 上下左右移动光标：上下左右或k、j、h、l
    • 移动光标到行首：0或g0

    • 移动光标到行末：$或A、shit+a（移动到行末并进入插入模式）

    • 移动光标到文件首行：gg

    • 移动光标到文件末行：G
    • 移动光标到指定行：num+gg

    文本操作：

    • 删除：
    • 删除光标后的字符：x代表删除光标后的单个字符，num+x代表删除光标后的num个字符
    • 删除光标前的字符：X代表删除光标前的单个字符，num+X代表删除光标前的num个字符
    • 删除从光标到移动目标的内容：d + 方向键只能删除单个字符或行
    • 删除到下一个单词开头：d + w
    • 删除到当前单词末尾：d + e
    • 删除到行尾：d$或D
    • 删除到行首：d0
    • 删除到文件开头：dgg
    • 删除（剪切）行：dd删除当前行，num+dd删除从光标开始的num行
    • 复制：yy复制当前行，num+yy从光标开始的num行
    • 粘贴：p在光标后粘贴，P在光标上一行粘贴
    • 选中：v从光标开始选中，可配合删除、复制、粘贴、剪切等操作
    • 撤销：u

    进入插入模式：

    • 在光标之前插入：i
    • 在光标之后插入：a
    • 在当前行的下方插入一个新行：o
    • 在当前行的上方插入一个新行：O

    进入命令模式：:

    进入块选择模式：

    • 功能：允许你选择矩形文本块（垂直选择），而不是常规的行或单词。
    • 按 Ctrl + v进入块选择模式。
    • 用 hjkl或方向键移动光标，选择矩形区域。
    • 执行操作（如删除、复制、插入等）。
    1.3.2.命令行模式下的基本操作

    文件操作：

    • 保存文件：:w
    • 保存文件并退出：:wq
    • 退出vim：:q
    • 强制退出vim不保存：:q!
    • 打开另一个文件：:e [文件名]

    搜索和替换：

    • 向下搜索关键词：/keyword，按n向下一个，按N向上一个，命令后加上\c代表忽略大小写
    • 向上搜索关键词：?keyword，按n向上一个，按N向下一个，命令后加上\c代表忽略大小写
    • 取消搜索：/不可能匹配的字符
    • 全文替换：:%s/is/IS/g
    • 当前行替换：:s/IS/is/g
    • 替换指定行：:1,5s/IS/is/g
    • 替换并不区分大小写：:%s/is/test/gi

    文本内容操作：

    • 语法格式：:[range] command [arguments]
    • :：进入命令行模式的触发键。
    • [range]：指定要操作的行范围。
    • command：要执行的操作命令（如 co, m, d）。
    • [arguments]：提供给命令的参数（如目标行号）。
    • 复制（Copy）：
    • 例：:1,2 co 3将第一行到第二行的所有文本复制到第三行之下。
    • 移动（Move）：
    • 例：:1,2 m 3将第一行到第二行的所有文本剪切到第三行之下。
    • 删除（Delete）：
    • 例：:1,2 d删除第一行到第二行的所有文本。

    其他操作：

    • 显示行号：set nu
    • 隐藏行号：set nonu
    • 打开帮助文档：:help [command]
    • 设置搜索高亮：:set hlsearch

    • 关闭搜索高亮：:set nohlsearch

    • 永久设置高亮与显示行号：vim /etc/vimrc

    1.3.3.批量注释

    添加注释

    1. vim打开需要操作的文件，光标放在需要注释内容的第一行，按ctrl+v选中所有需要注释的行的开头
    2. 选择完毕后，按大写的I键，输入注释符
    3. 最后按ESC键

    删除注释

    1. vim打开需要操作的文件，光标放在需要删除注释内容的第一行，按ctrl+v选中所有需要注删除释的行的开头
    2. 选择完毕后，按小写的d键，删除注释符
    3. 最后按ESC键
